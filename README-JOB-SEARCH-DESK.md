# Job Search Desk

A daily job search that runs in the cloud: it scans job boards and your job alert emails every morning, scores each posting on what you care about, and keeps everything on one job page in Claude.

To start, use the message Erik sent you. It walks you through making your private copy of this template and connecting Claude to it; then you type "start setup".
